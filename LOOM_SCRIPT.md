# Loom Talk Track

## 45-Second Version

Market Bubble Live Desk is a backstage producer feed for running a live Market Bubble show.

Instead of watching Twitch, Kick, and X in separate tabs, the operator gets one source-labeled feed with a simple read on every item.

The top strip tells the room four things immediately:

- `Live Segment`: what part of the show we are in.
- `Use Now`: what is worth acting on right now.
- `Heat`: which topic is building and whether it needs action or monitoring.
- `Handoff`: what is ready for hosts, clips, or segment notes.

The feed is not just raw chat. Each item is labeled by what it can become: an on-air question, a market beat, a segment segue, a clip candidate, or something to park for later.

So the producer is not asking, "What did chat say?"

They are asking, "What should we bring to the hosts next?"

That is the point of the desk: turn messy live audience input into a short, usable show rundown.

## Demo Flow

1. Start at the top brief.
2. Click `Use Now` to show only actionable items for the current segment.
3. Point out the `Potential` label on feed rows.
4. Click `Heat` to show topic context in Signal Radar.
5. Click `Handoff` to show the operator queue.
6. End on Producer Assist: this is the next best move for the room.

## Closing Line

For Market Bubble, this is not a generic chat aggregator. It is an internal live desk that helps the operator decide what is worth saying, saving, clipping, or parking while the show is happening.
